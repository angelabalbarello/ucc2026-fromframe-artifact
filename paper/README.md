# paper/: submitted version

This folder holds the manuscript **as submitted for double-blind review** to
IEEE/ACM UCC 2026 (anonymized, August 2026): `main.tex`,
`FromFrameToEpisode_UCC2026_final.pdf` and its figure.

It is **not** the camera-ready version. The published paper differs from it,
for example in the uniform-window SAR re-analysis, the corrected TTA_ef
definition, Algorithm 1, the reformulated invariant E2, and the sensitivity
analyses. Those post-acceptance analyses are in
`artifact/experiments/e11_camera_ready/` and
`artifact/experiments/k1_generator_correction/`. See `docs/PROVENANCE.md`.
